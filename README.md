# Aquaculture Scientific — journal website

Static HTML/CSS/JS site for a Porto Alegre–based international aquaculture journal.

## Open in a browser

1. Unzip or copy the `aquaculture-scientific` folder to your computer.
2. Double-click `index.html`, or in a terminal:

```bash
cd aquaculture-scientific
python3 -m http.server 8080
```

Then open http://localhost:8080

## Open in VS Code

1. File → Open Folder… → select `aquaculture-scientific`
2. Install the Live Server extension (Ritwick Dey)
3. Right-click `index.html` → Open with Live Server

Forms do not send files until you connect Open Journal Systems, eJournalPress, or a backend.

ISSN and indexing are marked as pending on purpose. Do not add Scopus, WoS, PubMed or a made-up ISSN until the identifiers exist.

Replace `editor@aquaculture-scientific.br` and the Avenida Ipiranga address with your real office before going live.
